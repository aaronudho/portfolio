# Aaron Udho: Engineering Portfolio

**Live site: https://aaronudho.github.io/Portfolio/**

Mechanical Engineering student (Minor in Mathematics) at Toronto Metropolitan University. The site is a video-game themed portfolio of my projects: a herringbone gear phone stand, a SolidWorks engine assembly, a 3D printed mechanical flower, an assistive kettle redesign, and more.

Built with React and Vite (JavaScript, HTML, CSS). `index.html` is the whole site packed into one file; the source code is in `portfolio-source-code.zip`.
